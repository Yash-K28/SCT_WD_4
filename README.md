# DAILYTASKS – To-Do List Web Application ✅

**DailyTasks – Your Day, Organized.** A modern and responsive To-Do List web application built using React.js, JavaScript, and CSS as part of SkillCraft Technology Web Development Task 04. It helps users organize daily activities, manage deadlines, track task progress, and stay productive with a simple and user-friendly interface.

## 🚀 Features

- **Add Tasks:** Easily create and add new tasks.
- **Edit Tasks:** Update existing task details whenever needed.
- **Delete Tasks:** Remove tasks that are no longer required.
- **Mark as Complete:** Track completed and pending tasks.
- **Due Date Selection:** Set deadlines for individual tasks.
- **Due Time Selection:** Schedule tasks with specific times.
- **Task Filtering:** Filter tasks by All, Active, and Completed.
- **Progress Tracking:** View completed and remaining tasks.
- **Local Storage:** Automatically saves tasks in the browser, so data remains available after refreshing the page.
- **Responsive Design:** Clean and user-friendly interface.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- CSS
- Vite
- Browser Local Storage

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Yash-K28/SCT_WD_4.git
```

### 2. Navigate to the Project Folder

```bash
cd SCT_WD_4
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

## 📖 How to Use

1. Enter your task name in the input field.
2. Select a due date and time (optional).
3. Click **Add Task** to create a task.
4. Mark tasks as completed using the checkbox.
5. Use the Edit option to update task details.
6. Delete tasks when they are no longer needed.
7. Use All, Active, and Completed filters to organize your tasks.
8. Track your productivity through the progress section.

## 💾 Data Storage

The application uses browser **Local Storage** to save task information. Your tasks remain stored even after refreshing or reopening the browser on the same device and browser.
